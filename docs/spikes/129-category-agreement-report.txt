Best case with YouTube's category alone: 124/296 =   42% of comparable
channels,   20% of all 629 subscriptions. Dropping the catch-alls:
103/191 =   54%, over   30% of subscriptions.

That best case is fitted on this very data — it picks each YouTube
category's most common filing after seeing the answers — so it is an
upper bound on what any mapping could achieve, not a forecast.

4. What a pre-filter would save
-------------------------------
Model calls skipped if the LLM is only invoked where YouTube has no
usable signal: 194 of 629 =   31% of calls.
Those 194 channels would be filed at about   54% accuracy — the
upper bound above — against a classifier pass costing ~1s per channel.
